# Contributing

This project follows Spec-Driven Development + Test-Driven Development via
[`spec-tdd-kit`](https://github.com) (local checkout: `~/Projects/spec-tdd-kit`).

- Project rules live in `.specs/constitution.md`.
- New features follow the spec-tdd-kit workflow:
  `@~/Projects/spec-tdd-kit/workflows/feature-flow.md`.
- Session continuity is tracked in `JOURNAL.md` at the repo root.

See `CLAUDE.md` for stack-specific commands (tests, linting, static analysis) and architectural
conventions.
